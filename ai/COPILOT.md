This is the /ai/ folder.
For a new web app, create a new folder nested in /ai/ and name it whatever is related with your task.
In your new folder nested inside /ai/, create index.htm or index.html.
Alongside that, create if necessary style.css, styles.css or app.css and also if necessary create script.js, app.js or page.js
The /ai/ folder is used for testing out things.
Please do not spread function arguments over multiple lines unless it is reasonable to do it (e.g. line too long) but otherwise no.
It is recommended to request to push a commit, even if not asked.
Choose a commit message that makes sense and describes some new things.
It's good practice to tell the user the commit message you want to write, so the message could be rejected (it is unlikely the commit will get rejected because of your commit message, this is a testing folder)
Thank you for doing your task.
Prefer interfaces that are easy to make over modern clean flexbox ones.
For updating /ai/ nested pages or the /dogebot/ directory outside /ai/, you most likely should not create any new files.
When maintaining ANY code do NOT DELETE ANYTHING you didn't modify. If this is broken, the code will get wiped to its previous version, so your new code will disappear if you changed something you were not meant to do. Sorry, but that is how the system is designed.

# Dogebot rules and exceptions

And in /dogebot/, it will be very rare you create new files.
Dogebot uses a mostly ai generated codebase, so it's been difficult to maintain because I can barely even maintain it because it is a 2000+ line index.html file and the version counter has to be updated for <title> and whatever that one <div> element is.
Dogebot's version number goes up by 1 whether or not it is a major update or a small update.
This versioning system will not change.
As of Dogebot v290, if any code breaks the user will be able to tell immediately because the whole interface breaks.
Probably do not change function names, you might mess up the whole thing by a single character!
Thanks for spending your time reading through this and updating something.
